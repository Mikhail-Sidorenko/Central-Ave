# Central-Ave

Дом в Говорово вся инженерная система.

Интерактивный план инженерных систем дома по проекту «Проект дома 88-96» (ООО «Движущая сила»).

## Как открыть
Скачайте `plan/index.html` и откройте в браузере. Вкладки: 1 этаж, 2 этаж, чердак.
Слои: кондиционеры, радиаторы и котёл, тёплый пол, освещение и шторы, канализация, вентиляция.
По клику на помещение — карточка: площадь, оборудование, группа щита, зона отопления.

## Структура
- `plan/index.html` — готовый план (один файл, открывается без интернета).
- `src/data.js` — все данные: помещения, стены, окна, оборудование. **Правки вносить сюда.**
- `src/template.html` — вёрстка и логика отображения.
- `src/build.py` — сборка: `python3 src/build.py` → обновляет `plan/index.html`.
- `src/rectify.py` — как сканы листов 3–5 приводились к координатам осей (для справки; пути внутри — исходные).
- `scans/` — выровненные по осям сканы планов (подложка).

## Статус данных
- **По проекту:** геометрия, экспликация, вентблоки ВК1/ВК2, дымоход котла, стояк канализации Ø110 (листы 3–5, 16, 17.4–17.5).
- **Решено:** модели кондиционеров Haier по спецификации от 06.08.2026.
- **Предварительно:** зоны тёплого пола, места радиаторов/коллекторов, группы освещения, места наружных блоков, разводка канализации.

## Открытые вопросы
- Система 1 (кассета AB71 + 1U70) — помещение не определено.
- Кабинет (2 эт.) — кондиционер не выбран.
- Н-3: 3U55S2SL5FA или 2U50S2SM1FA-3.
- Спальня 7 (2 эт., 22,85 м²): проверить привязку и мощность AS25.
- Щит Wiren Board, 12 групп уличного освещения, 3 шторы — места не заданы.
